# ian-wb.github.io

Personal portfolio site for Ian Wanderley — gameplay programmer.

**Live:** [ian-wb.github.io](https://ian-wb.github.io)

## Stack

Plain HTML, CSS, and JavaScript. No framework, no build step. Hosted on GitHub Pages.

## Running locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python -m http.server 5173
# or
npx serve .
```

Then visit `http://localhost:5173`.

## Files

- `index.html` — page structure
- `styles.css` — design system and visuals
- `script.js` — scroll behavior, animations, mobile menu
- `assets/` — images and screenshots
